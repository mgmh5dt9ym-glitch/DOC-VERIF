# Mobile upgrade

Cette version améliore l'affichage mobile sans modifier la logique métier.

Principales améliorations :
- page publique `/v/[code]` bord à bord sur téléphone ;
- header et logo redimensionnés pour les petits écrans ;
- document affiché à pleine largeur sur mobile ;
- administration avec marges et cartes adaptées aux écrans étroits ;
- QR plus grand et centré sur téléphone ;
- boutons pleine largeur et zones tactiles plus grandes ;
- formulaires d'upload et de branding optimisés pour mobile ;
- page de connexion présentée comme une carte mobile ;
- prévention du zoom automatique iOS sur les champs de formulaire.

La logique QR/domaine dynamique du projet est conservée.
